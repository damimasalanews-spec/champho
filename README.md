# CHAMP WORD V40.1 — Polished Mobile Landscape

CHAMP WORD is a polished Word UNO-style game shell with responsive landscape UI, local guest/demo play, profile dashboard, and Firebase integration hooks.

## Run
Serve this folder over HTTP(S). Open `index.html` through a web server rather than `file://`.

## Firebase
Replace the placeholder values in `firebase.js` with the real Firebase web-app configuration to enable online account and cloud features.

## Project
- `index.html` — game shell and screens
- `style.css` — polished UI styling
- `game.js` — interactions and game logic
- `firebase.js` — Firebase configuration hook
- `functions/` — Firebase Cloud Functions
- `assets/` — game artwork and profile assets
